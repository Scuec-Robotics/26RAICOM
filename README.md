Go2 分段智能巡迹控制系统
## 项目简介
**项目名称**：Unitree Go2 视觉分段巡线增强完整版
**硬件载体**：宇树 Go2 四足机器人 + Intel RealSense D435i 深度彩色相机
**通信框架**：unitree_sdk2py
**编程语言**：Python3
**适用场景**：机器人竞赛全自动赛道任务
整套程序单文件 `gou.py`，集成视觉黑线循迹、深度避障、直角弯道识别、窄道固定轨迹FSM、爬楼梯、红点任务、ORB特征标识识别、两次跳跃、中转平台检测、蓝色终点启停区全赛道逻辑；内置完整状态机，任务流程按照赛道时序逐级解锁功能，避免多逻辑冲突。

## 📋 全部功能清单
### 1. 多层加权黑线循迹（核心）
- ROI垂直划分为10层独立检测黑线
- 远端黑线丢失自动减速，提前预判弯道
- 分层权重：近处黑线权重更高，抑制远处杂线干扰
- PID位置闭环纠偏 + 一阶低通滤波平滑转向
- ROI上方区域最小二乘法拟合黑线走向
- 深度掩码过滤远距离噪点
- 障碍物前景近距离黑线过滤，防止物体误识别赛道

### 2. 90°直角弯道自主识别
多条件综合判定直角：上层无线、底层存在黑线；
识别后执行**预直行补偿 + 固定时长盲转弯**，转弯结束重新搜寻黑线；
依托深度相机过滤障碍物产生的虚假黑线，降低误触发概率。

### 3. 窄道模式（有限状态机FSM固定路径）
赛道前段**首次丢线自动触发窄道逻辑**；
内置完整预设轨迹：多段直行、停顿、左右转弯、横向侧移微调；
支持前方距离阈值提前结束直行、障碍物临近提前切入转弯；
最后一轮转弯支持**黑线实时检测+角度补偿**，自动修正累积偏差。
窄道执行完成后解锁【爬楼梯功能】。

### 4. 爬楼梯模式
触发条件：楼梯专属上层ROI黑线宽度剧烈突变；
三段式动作流程：纯直行 → 边转弯边前进 → 反向侧移修正位置；
自动切换 `ClassicWalk` 稳定爬楼梯步态；
爬楼结束短时仅使用底层近处黑线，规避十字岔路干扰。
楼梯完成后解锁【中转平台检测】。

### 5. 中转平台双重检测（深度+颜色）
仅楼梯完成后开启检测；
- 第1个平台：自动转弯避让 + 短距直行，随后恢复循迹
- 第2个平台：原地静止等待指定时长

### 6. 红点完整任务流水线
视觉识别红色圆形标记
→ PID循迹持续靠近
→ 达到视觉极限补偿固定距离前进
→ 左转序列
→ 后退小段距离
→ ORB标识识别并执行动作
→ 右转回归黑线
> **红点任务完成后，才启用蓝色终点检测、解锁第二次跳跃**

### 7. ORB特征图案识别
识别3类安全警示标识：
1. 当心触电 → 伸懒腰动作
2. 当心氧化剂 → 打招呼动作
3. 当心辐射 → 前后灯光闪烁
支持多帧确认防误识别、识别冷却时间、长时间未识别微量前进搜寻标识。

### 8. 双段跳跃机制
- 第一次跳跃：窄道执行前，黑线垂直断裂（截断）触发
- 第二次跳跃：红点任务完成延时2.8s后开启检测
跳跃结束自动执行摆头搜索黑线、自动对准赛道；
起跳前补偿前进固定距离，保证起跳点位精准。

### 9. 蓝色终点启停区（任务终点）
仅红点流程结束后启用蓝色色块识别；
识别蓝区完整流程：
停止 → 直行指定距离 → 左转固定角度 → 终点短距前进 → 趴下结束整套任务。

### 10. 分级丢线恢复策略
1. **窄道前第一次丢线 → 直接触发窄道模式**
2. 窄道/楼梯完成后丢线 → 记忆方向惯性转弯（LOST_MEMORY）
3. 惯性转弯仍找不到黑线 → 大范围双向摆头搜索黑线（LOST_SEARCH）

### 11. 相机预热系统
机器人初始保持趴卧，采集40帧图像预热相机，预热完毕再执行站立，解决启动初期画面抖动、识别不稳定问题。

### 12. 前方深度雷达避障
实时采样深度图像中心区域；
小于安全距离自动减速；障碍物距离＜0.22m紧急触发直角转弯规避。

### 13. 步态管理
支持自由行走/经典爬楼步态切换；同时兼容新旧两套Unitree步态API。

## 🚀 运行启动命令
### 1. 带可视化窗口（调试首选，查看视觉画面）
```bash
python3 gou.py eth0 --show
```
### 2. 无头后台运行（无显示器、机器人本机部署）
```bash
python3 gou.py eth0
```
### 3. 限制程序最大运行时长（示例：180秒自动终止）
```bash
python3 gou.py eth0 --duration 180 --show
```

**参数说明**
- `eth0`：有线网卡名称，USB外接网卡改为`usb0`
- `--show`：开启OpenCV图像窗口，实时观测视觉识别效果
- `--duration` 可选参数，程序最大运行时长（单位：秒）

**窗口快捷键**：图像窗口按 `ESC` / `q` 安全终止程序

## 🎛️ 代码内参数分区（赛场快速调参区域）

## ⚠️ 安全操作规范【重点】
1. **首次调试务必悬空抬起机器人，禁止落地直接运行！**
2. 修改速度参数循序渐进增大，窄道、跳跃、爬楼梯优先低速测试
3. 机器人站立运行时，不要遮挡RealSense深度镜头
4. 程序异常优先使用 `Ctrl+C` 正常退出，代码会自动执行StopMove+StandDown
5. 场地光照变化优先调整黑线阈值 `self.black_threshold`

## 🛠️ 常见故障排查
### 1. RealSense相机无法启动
```bash
sudo chmod 666 /dev/video*
```
检查USB线缆供电，确认 librealsense 正常识别设备

### 2. ORB模板打印找不到文件
确认**文件夹名称严格为 templates**，图片文件名与代码内`SIGN_FILES`完全一致，区分大小写。

### 3. 无法连接Go2机器人
- 确认网卡参数`eth0`和本机网卡匹配
- 上位机IP与Go2处于同一局域网
- 关闭防火墙，确认Unitree服务正常

### 4. 黑线识别不稳定、光照敏感
优先调整：`self.black_threshold`，强光加大数值，暗光降低；
同步可调整`black_threshold_high`楼梯检测阈值。

### 5. 直角频繁误触发
适当增大 `corner_confirm_frames`；检查障碍物过滤距离`OBSTACLE_FILTER_DIST`。

### 6. 跳跃不触发
观察终端打印三段灰度比例，微调截断判定系数`0.53`。

## 📝 竞赛修改快速指引
1. 赛道距离变短/变长 → 修改对应状态内【帧数/时长】
2. 转弯角度偏大偏小 → 修改角速度yaw或持续时间
3. 需要删除某项任务（例如取消跳跃）
   直接注释对应跳跃检测`if`判断块即可
4. 新增标识任务：扩展`SignID`枚举、新增图片、补充`execute_action_by_id`动作分支
